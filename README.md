# Titanic Dataset Analysis

## Data Science with Python Internship – Task 2

### Project Overview
This project analyzes the Titanic dataset using Python
to understand passenger survival patterns.

### Tools and Technologies
- Python
- Pandas
- Seaborn
- Matplotlib
- Jupyter Notebook

### Project Objectives
1. Load the Titanic dataset.
2. Clean missing values.
3. Analyze survival by gender.
4. Analyze survival by passenger class.
5. Analyze survival by age group.
6. Create data visualizations.

### Key Findings
- Female survival rate: 74.20%
- Male survival rate: 18.89%
- First class survival rate: 62.96%
- Children had the highest survival rate: 57.97%.

### Visualizations
- Survival by Gender
- Survival by Passenger Class
- Passenger Age Distribution
